## Tecnologias

- React
- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) usa [Oxc](https://oxc.rs)
- Tailwind


## Como rodar

### Desenvolvimento

```shell
npm run install:all
npm run dev:server
npm run dev:client
```

### Produção

```shell
npm run install:all
npm run build
npm run start:prod
```
